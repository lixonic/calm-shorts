# Preview screenshots

Captured on 13 October 2026 from the running browser preview and localhost admin at `http://127.0.0.1:8767/`.

The activity images retain the entire viewer: branding, prompt, cues, choices, immediate Continue action, and footer. The playback and admin images include their surrounding desktop page. Counts and aurora colors came from the real shuffled session.

Open Text prompts in the separate admin to capture the editor. These are browser-preview captures; the installed APK uses the Flutter interface.
